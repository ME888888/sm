# 真武汤——少阴阳虚水泛主方

## 出处与组成

真武汤出自《伤寒论》第82条，是治疗少阴病阳虚水泛的经典方剂，又名"玄武汤"。

**组成：**
- 茯苓三两
- 芍药三两
- 生姜三两（切）
- 白术二两
- 附子一枚（炮，去皮，破八片）

**煎服法：** 以水八升，煮取三升，去滓，温服七合，日三服。

---

## 辨证要点

### 真武汤证的典型表现

| 症状 | 机理 |
|------|------|
| 小便不利 | 肾阳虚衰，水湿不化 |
| 四肢沉重疼痛 | 水湿浸渍四肢肌肉 |
| 肢体浮肿 | 水湿泛溢肌肤 |
| 腹痛下利 | 水寒之气内盛 |
| 苔白滑 | 水湿内停之象 |
| 脉沉细 | 阳虚水泛之脉 |

### 真武汤与苓桂术甘汤的鉴别

| | 真武汤 | 苓桂术甘汤 |
|---|---|---|
| 病机 | 肾阳虚水泛（少阴） | 脾阳虚水停（太阴） |
| 症状 | 畏寒肢冷、腰以下肿甚 | 胸胁支满、心下逆满 |
| 治疗 | 温阳利水 | 温脾化饮 |

---

## 方义解析

**附子** — 君药，温壮肾阳，散寒逐湿

**茯苓** — 臣药，健脾渗湿，利水消肿

**白术** — 佐药，健脾燥湿，助茯苓利水

**生姜** — 佐药，温散水气，助附子散寒

**芍药** — 使药，敛阴舒筋，缓急止痛，制附子之燥

> 附子温肾阳，茯苓、白术健脾利湿，生姜温散水气，芍药敛阴缓急。全方温肾健脾以利水，是治疗阳虚水泛的代表方。

---

## 临床应用

### 适应病症
- 慢性肾炎、肾病综合征（水肿）
- 心力衰竭（阳虚水泛型）
- 肺心病（咳喘伴水肿）
- 前列腺增生（排尿不利）
- 慢性胃肠炎（阳虚水泻）
- 风湿性关节炎（寒湿痹痛）
- 梅尼埃病（痰饮上泛）

### 加减变化

| 证型 | 加减 |
|------|------|
| 咳甚 | 加五味子、细辛、干姜 |
| 下利 | 去芍药，加干姜 |
| 呕吐 | 重用生姜 |
| 水肿甚 | 加泽泻、猪苓 |

## 真武汤的衍化

| 方剂 | 变化 | 主治 |
|------|------|------|
| 附子汤 | 真武汤去生姜，加人参 | 阳虚寒湿身痛 |
| 真武汤合五苓散 | 两方合用 | 脾肾阳虚，水湿内停 |
| 春泽汤 | 真武汤合理中汤 | 阳虚水湿吐泻 |

---

## 禁忌

⚠️ **以下情况慎用真武汤：**

1. **阴虚火旺** — 口干咽燥、舌红少苔
2. **湿热蕴结** — 苔黄腻、小便黄赤
3. **实热内结** — 便秘腹胀
4. **孕妇** — 附子温燥，需在医师指导下使用

---

## 结语

真武汤是治疗阳虚水泛的代表方，其病机核心是"少阴阳虚，水湿内停"。方名"真武"，为北方之神，司水之职，以喻本方温阳利水之功。临证凡见小便不利、肢体浮肿、畏寒肢冷、舌淡苔白、脉沉细者，皆可考虑使用真武汤。
