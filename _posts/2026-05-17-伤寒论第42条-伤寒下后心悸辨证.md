## 条文原文

> **伤寒表不解，心下有水气，干呕发热而咳，或渴，或利，或噎，或小便不利，少腹满，或喘者，小青龙汤主之。**
> ——《伤寒论》第42条

## 释义

本条论述太阳伤寒表证不解，兼有寒饮内停的证治，即著名的小青龙汤证。

条文首言"伤寒表不解"，明确指出太阳伤寒麻黄汤证仍在；"心下有水气"，点明本证的核心病机——外寒内饮。水饮停于胃腑（心下），上逆犯肺，中阻脾胃，故见干呕、咳嗽等症。

症状解析：

| 症状 | 病机 |
|------|------|
| **干呕** | 水饮犯胃，胃气上逆 |
| **发热** | 表邪未解，卫阳被遏 |
| **咳** | 水饮射肺，肺失宣降 |
| **渴** | 水饮内停，津不上承（多为渴而不欲饮） |
| **利** | 水饮下趋肠道 |
| **噎** | 水气阻滞，气机不畅 |
| **小便不利，少腹满** | 水蓄膀胱，气化不行 |
| **喘** | 水饮射肺，肺气上逆 |

"或"字揭示小青龙汤证的多变——水饮为病，变动不居，随气机上下内外，留滞何处则为何症，故不必悉具，但见一二即可用之。

## 病机分析

| 层面 | 病机 |
|------|------|
| 表（太阳） | 风寒束表，卫闭荣郁 |
| 里（寒饮） | 水气内停，脾胃阳虚 |
| 整体 | 外寒内饮，表里俱病 |

**核心病机**：外有风寒，内有寒饮，内外合邪。

刘渡舟先生指出："小青龙汤证的关键在于'表不解'与'心下水气'同时存在。表寒不解，水饮内停，二者相互影响，必须表里双解。"

## 方剂组成

**小青龙汤：**

麻黄三两（去节）、芍药三两、干姜三两、甘草三两（炙）、桂枝三两（去皮）、细辛三两、五味子半升、半夏半升（洗）

| 药物 | 功效 |
|------|------|
| 麻黄、桂枝 | 发汗解表，宣肺平喘 |
| 芍药 | 养阴和营，佐制麻桂之辛散 |
| 干姜、细辛 | 温化寒饮，散寒止咳 |
| 五味子 | 敛肺止咳，以防辛散太过 |
| 半夏 | 燥湿化痰，降逆止呕 |
| 甘草 | 调和诸药 |

> **注：** 方剂剂量历代有争议，临床使用须核对权威文献并在医师指导下进行。

## 方解

陈修园《伤寒论浅注》谓："此方为治表寒内饮之神剂。麻黄、桂枝发汗散寒，干姜、细辛温化寒饮，五味、半夏止咳化痰，芍药、甘草调和营卫。表里双解，诸症自除。"

小青龙汤的配伍特点：
- **辛散之中佐以酸收**：麻黄、细辛、干姜皆辛温发散太过，五味子酸收以敛肺气、止咳喘，使散不伤正
- **温化之中兼顾发表**：外散表寒，内化寒饮，表里同治

## 煎服法

以水一斗，先煮麻黄，减二升，去上沫，内诸药，煮取三升，去滓。温服一升。

**药后调护：**
1. 温覆取微汗——仿桂枝汤法
2. 药后避风寒
3. 慎防过汗——本方麻黄、细辛皆辛温燥烈

> ⚠️ 小青龙汤中麻黄有升压作用，高血压患者慎用；细辛有毒（主要成分挥发油），须严格控制用量《中国药典》规定细辛用量为1-3g；半夏有妊娠禁忌，孕妇慎用或忌用。

## 名家注释

**胡希恕《伤寒论讲座》：**
"小青龙汤证的关键是'表不解，心下水气'。干呕、咳嗽是水气上逆的表现，或渴、或利、或噎皆是水饮变动不居的反应。本方治外寒内饮，疗效确切。"

**刘渡舟《伤寒论讲义》：**
"'心下有水气'是辨证的眼目。水饮为阴邪，非阳气不行，故用干姜、细辛温化之。水饮咳嗽的特点是痰多清稀、背寒怕冷，夜间及晨起加重。"

**郝万山《伤寒论课程讲稿》：**
"从现代医学角度看，小青龙汤证常见于支气管哮喘、慢性支气管炎急性发作，符合'外寒内饮'的病理特点。方中麻黄扩张支气管，细辛抗炎，半夏祛痰，五味子镇咳，恰合病机。"

## 鉴别要点

### 小青龙汤证与麻黄汤证的鉴别

| | 麻黄汤证（第35条） | 小青龙汤证（本条） |
|---|---|---|
| 病机 | 风寒束表，卫闭荣郁 | 表寒 + 寒饮内停 |
| 主症 | 发热恶寒、身疼腰痛、喘 | 干呕、咳、喘（兼有表证） |
| 痰饮 | 无痰饮内停 | 痰多清稀如水 |
| 口渴 | 不渴 | 渴而不欲饮（或不渴） |
| 舌苔 | 薄白 | 白滑、水滑 |

### 寒饮咳嗽与热邪咳嗽的鉴别

| | 寒饮咳嗽 | 热邪咳嗽 |
|---|---|---|
| 痰色 | 清稀如水，泡沫痰 | 黄稠 |
| 口渴 | 渴而不欲饮 | 口渴喜冷饮 |
| 舌苔 | 白滑 | 黄干燥 |
| 小便 | 清长 | 黄短 |

## 临床应用

1. **支气管哮喘急性发作**属外寒内饮者——恶寒发热、咳喘痰稀如水
2. **慢性支气管炎急性发作**——咳喘痰多清稀，夜间及晨起加重
3. **COPD急性加重**——咳喘痰多泡沫状，畏寒肢冷
4. **过敏性鼻炎**见鼻塞流清涕、咳嗽属寒饮者
5. **老年性肺心病**属寒饮射肺者

## 总结

第42条论述小青龙汤证的典型证治，其辨证要点为：
- **表不解**：发热恶寒、无汗
- **心下水气**：干呕、咳嗽、痰稀清冷
- **或然证**：渴、利、噎、小便不利、少腹满

治法：发汗解表，温化寒饮

本方为治疗外寒内饮咳嗽的经典方剂，与第40条、第41条合参，方能全面掌握小青龙汤的临床应用。
