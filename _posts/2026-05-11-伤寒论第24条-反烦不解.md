## 条文原文

> **太阳病，初服桂枝汤，反烦不解者，先刺风池、风府，却与桂枝汤则愈。**
> ——《伤寒论》第24条

---

## 条文释义

### 逐字解析

|| 词句 | 含义 |
|------|------|
| **初服桂枝汤** | 首次服用桂枝汤后 |
| **反烦不解** | 反而出现烦躁，症状未解 |
| **先刺风池、风府** | 先用针刺泻风池、风府穴 |
| **却与桂枝汤则愈** | 然后再服桂枝汤则可痊愈 |

### 病机分析

"反烦"是本条的关键症状，为何服桂枝汤后反而出现烦躁？

| 病机 | 解析 |
|------|------|
| **邪气较重** | 桂枝汤药轻力薄，难以顿挫邪势 |
| **经络郁滞** | 邪郁经络，阳气不舒，郁而化热 |
| **正邪相争激烈** | 药力助正，与邪相搏，暂现烦躁 |

**胡希恕先生**注："反烦者，非药不对证，乃邪气太盛，药力不足以制之。此时针刺以泻其邪，再与汤药则效。"

**刘渡舟先生**注："此条示人针药并用之法。药力不及之处，以针刺辅助，针药结合，效如桴鼓。"

---

## 刺法解析

### 风池穴

| 项目 | 内容 |
|------|------|
| 定位 | 项后枕骨下两侧凹陷中（当枕大神经出处） |
| 归属 | 足少阳胆经 |
| 功效 | 祛风解表，清利头目 |
| 刺法 | 针尖微下，向鼻尖方向斜刺0.5-0.8寸 |

### 风府穴

| 项目 | 内容 |
|------|------|
| 定位 | 后发际正中直上1寸（枕骨大孔凹陷处） |
| 归属 | 督脉 |
| 功效 | 祛风散寒，清热开窍 |
| 刺法 | 向下颌方向斜刺0.5-0.8寸（不可深刺） |

### 刺法要义

```
风池（足少阳）→ 祛风清热，通利头窍
     ↓
风府（督脉）→ 统摄阳气，祛风散寒
     ↓
二穴合用 → 疏通经络，泄热祛邪
```

**针刺目的**：疏通经络泄热，为桂枝汤助力

## 名家注释

### 胡希恕注

> 服桂枝汤后反烦，是邪气太盛，郁于经络，不得发越所致。针刺风池、风府者，以穴道疏通经络，泄其郁热，然后与桂枝汤则邪去正安。此法在针灸临床上至今仍常用。

### 刘渡舟注

> 仲景立法，当用汤药用汤药，当用针刺用针刺，随证施治，灵活变通。本条示人以针药并用之法，尤其对于表邪较重、郁滞经络之证，单用药力不及，当配合针刺。

### 郝万山注

> 从临床看，某些外感热病初起，邪气较盛，单纯使用解表药效果不显时，配合针刺治疗可以提高疗效。风池、风府是治疗外感的要穴，针刺可以疏通经络，助桂枝汤发散表邪。

## 临床应用

### 适用指征

1. **外感病重**：服解表药后症状不减，反烦不解
2. **头痛项强**：风寒感冒头痛剧烈，针药并用
3. **高热不退**：表邪郁滞，热势不解
4. **面赤烦躁**：邪郁化热，上扰清窍

### 针药并用原则

| 情况 | 处理 |
|------|------|
| 药轻邪重 | 先刺后药 |
| 邪郁经络 | 针刺配合 |
| 兼有表里 | 表里同治 |
| 体质壮实 | 针刺泻邪 |

### 现代拓展应用

- **流感高热**：奥司他韦配合针刺风池、风府
- **病毒性感冒**：解表药配合大椎刺血拔罐
- **偏头痛**：川芎茶调散配合针刺风池、太阳

## 鉴别要点

### 与药不对证的鉴别

|| 本条证（药轻邪重） | 药不对证 |
|--------|------------------|----------|
| 服药后反应 | 烦（正邪相争） | 可能是下利、汗出过多等 |
| 处理方法 | 先刺后药 | 须更换方剂 |
| 预后 | 刺后与桂枝汤则愈 | 可能加重或变证 |

### 与第26条（白虎加人参汤证）的鉴别

|| 第24条 | 第26条 |
|--------|--------|--------|
| 病机 | 邪郁经络 | 邪入阳明 |
| 主症 | 反烦不解 | 大烦渴不解 |
| 治疗 | 针刺+桂枝汤 | 白虎加人参汤 |
| 热型 | 表郁发热 | 里热大渴 |

## 总结

第24条论述太阳病邪气较盛时的特殊治法：

- **症状特点**：服桂枝汤后反烦不解
- **病机关键**：药轻邪重，经络郁滞
- **治疗要义**：针药并用，先刺后药
- **取穴要旨**：风池祛风清热，风府散寒祛邪

**辨证要点**：表邪郁滞较重，单纯药物难以顿挫

**治法创新**：开针药并用之先河，示人灵活施治之法

本条体现了仲景"随证治之"的灵活治疗思想，为后世针药结合治疗外感病树立了典范。
