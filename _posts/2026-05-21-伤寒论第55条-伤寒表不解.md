## 条文原文

> **伤寒表不解，心下有水气，干呕、发热而咳，或渴、或利、或噎、或小便不利、少腹满、或喘者，小青龙汤主之。** ——《伤寒论》第55条

## 释义

本条论述外感寒邪、内停水饮的证治。伤寒表不解，指太阳病表证仍在；"心下有水气"，指素有水饮停聚于胃（心下）。外寒引动内饮，水寒射肺，肺失宣降，故见干呕、发热、咳喘等症。

**陈修园《伤寒论浅注》：** "此条论外寒引动内饮之证。'伤寒表不解'是言病因，'心下有水气'是言素因。外因伤寒，内因水饮，两因相合，搏结于中。水寒射肺则咳喘，犯胃则干呕，水气不化则渴、利、噎、小便不利、少腹满。"

## 病机分析

| 要素 | 分析 |
|------|------|
| 病机 | 外寒内饮（水寒射肺） |
| 病位 | 表（太阳）+里（心下水饮） |
| 病性 | 外寒内饮证 |
| 主症 | 干呕、发热、咳喘 |
| 或见证 | 渴、利、噎、小便不利、少腹满、喘 |
| 治法 | 解表散寒，温化水饮 |
| 主方 | 小青龙汤 |

**刘渡舟教授解读：**
"小青龙汤证的关键是'外寒内饮'。外寒宜辛温发散，内饮宜温化渗利。小青龙汤集麻桂之发汗、细辛干姜之温化于一体，使外邪得解，内饮得化，实为治疗外寒内饮的经典方剂。"

**外寒与内饮的关系：**
- 内饮为本：患者素有水饮内停（脾肾阳虚，水湿不化）
- 外寒为诱：感受风寒，外寒引动内饮
- 表里同病：外有风寒表证，内有寒饮伏肺

## 小青龙汤方解

| 药物 | 功效 | 配伍意义 |
|------|------|----------|
| 麻黄 | 发汗解表，宣肺平喘 | 散外寒 |
| 桂枝 | 助麻黄发汗散寒 | 温阳化饮 |
| 芍药 | 养血和营，防麻桂过散 | 佐制 |
| 细辛 | 温肺化饮，助麻黄散寒 | 散寒化饮 |
| 干姜 | 温中散寒，温化水饮 | 温里 |
| 半夏 | 燥湿化痰，和胃止呕 | 化饮 |
| 五味子 | 收敛肺气，止咳平喘 | 敛肺 |
| 甘草 | 调和诸药 | 和中 |

**配伍特点：** 麻黄、桂枝相须为用，发汗散寒；细辛、干姜、半夏温化水饮；五味子酸敛肺气，止咳平喘，防诸药辛散太过。全方散中有收，开中有阖，为治疗外寒内饮的经典配伍。

**胡希恕先生解读：**
"小青龙汤之妙，在五味子与细辛的配伍。五味子酸收，细辛辛散，一收一散，既能温化寒饮，又不耗散肺气。此方治外寒内饮之咳喘，效如桴鼓。"

## 临床应用

**辨证要点：**
- 咳喘，痰白清稀（呈泡沫状）
- 干呕（痰饮犯胃）
- 发热恶寒（表证）
- 苔白滑，脉浮紧或弦滑
- 或有口渴（水饮不化）、小便不利（气化失常）

**鉴别要点：**

| | 小青龙汤证 | 麻黄汤证 | 桂枝加厚朴杏子汤证 |
|--|------------|----------|------------------|
| 病机 | 外寒内饮 | 卫闭营郁 | 素有喘疾，外感风寒 |
| 主症 | 咳喘+干呕+表证 | 咳喘+无汗+身疼 | 咳喘+汗出+恶风 |
| 痰色 | 白稀泡沫 | 清稀 | 白 |
| 治法 | 解表化饮 | 发汗解表 | 调和营卫，降气平喘 |

**现代应用：**
- 支气管哮喘（寒哮）
- 慢性支气管炎（外寒内饮型）
- 过敏性鼻炎（肺寒饮停）
- 肺炎（寒饮蕴肺型）
- 心源性哮喘（水气凌心）
- 胸腔积液（寒水积胸）

**郝万山教授经验：**
"小青龙汤是治疗寒饮咳喘的效方，但用之不当容易出现副作用。若患者已有自汗，麻黄、桂枝宜减量或去之，加重五味子、白芍用量；若心下有水气兼有烦躁，可加石膏清热，即小青龙加石膏汤。"

## 名家注释

**刘渡舟《伤寒论讲义》：**
"'心下有水气'是辨证关键。水气泛指一切水液代谢障碍所形成的病理产物，包括痰、饮、水、湿。小青龙汤所治之'水气'，主要指寒饮而言。寒饮内停，遇外寒引动，上逆射肺，则为咳喘；内走胃肠，则为干呕、下利。"

**郝万山《伤寒论课程讲稿》：**
"小青龙汤的或见证多达六个（渴、利、噎、小便不利、少腹满、喘），体现了水饮为病变化多端的特点。临床上但见咳喘痰稀、恶寒发热、苔白滑者，即可考虑小青龙汤。"

**胡希恕《伤寒论讲座》：**
"小青龙汤是麻黄汤的变方，治外寒内饮之证。与麻黄汤相比，本方去杏仁，加细辛、干姜、五味子、半夏，增强了温化寒饮的力量。若无表证，仅有寒饮咳喘，可去麻黄，改用苓甘五味姜辛汤。"

## 煎服法（参考）

| 药物 | 现代参考剂量 |
|------|------------|
| 麻黄三两（去节） | 9g |
| 桂枝三两（去皮） | 9g |
| 芍药三两 | 9g |
| 细辛三两 | 3g |
| 干姜三两 | 9g |
| 甘草三两（炙） | 9g |
| 半夏半升（洗） | 9g |
| 五味子半升 | 6g |

以水一斗，先煮麻黄减二升，去上沫，内诸药，煮取三升，去滓。温服一升。

若口渴者，去半夏，加瓜蒌根三两；若微利，去麻黄，加芫花；若噎者，去麻黄，加附子；若小便不利，少腹满，去麻黄，加茯苓四两；若喘，去麻黄，加杏仁半升。

⚠️ **剂量仅供参考，临床使用须在医师指导下进行。本方含麻黄，心血管疾病患者慎用。**

## 总结

第55条论述小青龙汤证，为外寒内饮的典型证治。外有伤寒表不解，内有心下水气（水饮），水寒射肺则咳喘，犯胃则干呕，水气变动不居，可致渴、利、噎、小便不利、少腹满等多种或见证。

小青龙汤以麻黄、桂枝发汗解表，细辛、干姜温化寒饮，五味子、半夏敛肺降逆，共奏"解表散寒、温化水饮"之功。本方为治疗寒饮咳喘的经典方剂，临床应用广泛，但须在医师指导下使用。
