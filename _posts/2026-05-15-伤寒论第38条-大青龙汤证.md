## 条文原文

> **太阳中风，脉浮紧，发热恶寒，身疼痛，不汗出而烦躁者，大青龙汤主之。若脉微弱，汗出恶风者，不可服之，服之则厥逆，筋惕肉瞤，此为逆也。**
> ——《伤寒论》第38条

## 释义

本条论述大青龙汤证的典型脉证、病机及禁忌，是《伤寒论》中治疗外寒内热、表里俱实的重要条文。

条文首言"太阳中风，脉浮紧"，初看似乎矛盾——中风当浮缓，为何脉浮紧？刘渡舟先生指出：此处"太阳中风"是广义言之，实指伤寒表实之重证，因其证候比麻黄汤更重、更剧，故以"中风"借代言之。

核心症状解析：
- **脉浮紧**：风寒外束，卫闭荣郁
- **发热恶寒，身疼痛**：风寒表实证，与麻黄汤证相似，但更重
- **不汗出**：寒邪凝敛，玄府紧闭，为关键见症
- **烦躁**：寒束更甚，阳郁化热，热扰心神

大青龙汤为发汗峻剂，主治外寒内热、表里俱实之证。

## 病机分析

| 层面 | 病机 |
|------|------|
| 表（太阳） | 风寒束表，卫阳被遏，荣卫凝滞 |
| 里（阳明） | 阳郁化热，热扰心神 |
| 整体 | 表寒里热，表里俱实 |

**大青龙汤证与麻黄汤证的鉴别：**

| | 麻黄汤证（第35条） | 大青龙汤证（本条） |
|---|---|---|
| 寒热 | 发热恶寒 | 发热恶寒更重 |
| 疼痛 | 身疼腰痛 | 身疼痛更剧 |
| 汗出 | 无汗 | 无汗（更甚） |
| 脉象 | 浮紧 | 浮紧（更甚） |
| 兼症 | 喘 | 烦躁 |
| 病机 | 表寒 | 表寒里热 |

## 方剂组成

**大青龙汤：**

麻黄六两（去节）、桂枝二两（去皮）、甘草二两（炙）、杏仁四十枚（去皮尖）、生姜三两（切）、大枣十枚（擘）、石膏如鸡子大（碎）

| 药物 | 作用 |
|------|------|
| 麻黄 | 辛温发汗，开表散寒 |
| 桂枝 | 解肌祛风，助麻黄发汗 |
| 杏仁 | 宣降肺气，止咳平喘 |
| 石膏 | 辛寒清热，除烦解热 |
| 生姜、大枣 | 调和营卫，固护脾胃 |
| 甘草 | 调和诸药 |

> **注：** 方剂剂量历代有争议，临床使用须核对权威文献并在医师指导下进行。

## 方解

大青龙汤由麻黄汤倍麻黄加石膏、生姜、大枣组成。

- **麻黄汤倍麻黄** → 发汗之力更强，主散表寒
- **加石膏** → 清宣郁热，除烦躁
- **加生姜、大枣** → 调和营卫，兼护脾胃

陈修园《伤寒论浅注》谓："大青龙汤为治表寒里热之神剂，麻黄石膏并用，一开一合，使表里双解。"

## 煎服法

以水九升，先煮麻黄，减二升，去上沫，内诸药，煮取三升，去滓。温服一升，取微似汗。

**注意事项：**
- 汗出多者，温粉粉之（扑身止汗）
- 一服汗者，停后服
- 若复服，汗多亡阳遂虚，恶风烦躁，不得眠

## 名家注释

**胡希恕《伤寒论讲座》：**
"大青龙汤证的关键在于'不汗出而烦躁'。不汗出是表实，烦躁是里热，麻黄汤原方加石膏即能解决。若脉微弱、汗出恶风者，乃阳虚之证，禁服本方。"

**刘渡舟《伤寒论讲义》：**
"'若脉微弱，汗出恶风者，不可服之'——此为禁服条文。脉微弱为阳虚，汗出恶风为表虚，误服大青龙必致亡阳厥逆。"

**郝万山《伤寒论课程讲稿》：**
"大青龙汤发汗力强，为青龙汤中之峻剂。临床运用须确认为表寒里热、表实无汗、烦躁明显者，方可投之。"

## 禁忌（九禁）

大青龙汤发汗峻猛，下列情况禁用：
1. 脉微弱、汗出恶风（阳虚不固）
2. 咽喉干燥（阴虚）
3. 淋家（下焦湿热）
4. 疮家（气血两虚）
5. 衄家（阴血不足）
6. 亡血家（气血大虚）
7. 汗家（阳气已虚）
8. 寒中少阴（阳虚寒盛）
9. 脉尺中迟（营血不足）

## 临床应用

1. **流感（重型伤寒）**：高热恶寒、身痛剧烈、无汗烦躁
2. **大叶性肺炎（表寒里热）**：符合麻黄汤证更兼烦躁
3. **急性肾炎水肿（表实）**：风水泛滥、表实无汗
