# 小柴胡汤——少阳病主方

## 出处与组成

小柴胡汤出自《伤寒论》第96条，是治疗少阳病的经典方剂，被誉为"和解少阳的总方"。

**组成：**
- 柴胡半斤
- 黄芩三两
- 人参三两
- 半夏半升（洗）
- 甘草三两（炙）
- 生姜三两（切）
- 大枣十二枚（擘）

**煎服法：** 以水一斗二升，煮取六升，去滓，再煎取三升，温服一升，日三服。

---

## 辨证要点

### 少阳病的"七大症"

| 症状 | 机理 |
|------|------|
| 寒热往来 | 邪正交争于半表半里 |
| 胸胁苦满 | 肝胆经气不利 |
| 默默不欲饮食 | 肝胆犯胃，胃气不和 |
| 心烦喜呕 | 胆热上扰，胃气上逆 |
| 胸中烦而不呕 | 热聚胸中，胃气未伤 |
| 口苦 | 胆热上蒸 |
| 咽干、目眩 | 津液受伤，少阳经脉失养 |

### 少阳病的特点

少阳病位在半表半里，既非完全在表，又非完全在里，表现为枢机不利，正邪分争。治疗大法为"和解"，不可发汗、吐、下。

---

## 方义解析

**柴胡** — 君药，轻清升散，疏解少阳郁滞

**黄芩** — 臣药，清泻胆热，与柴胡相配和解少阳

**人参、半夏** — 佐药，健脾和胃，降逆止呕

**生姜** — 佐药，助半夏和胃，兼散表邪

**大枣、甘草** — 使药，健脾益气，调和诸药

> 柴胡、黄芩为和解少阳的核心；人参、甘草健脾扶正；半夏、生姜和胃降逆。全方寒热并用，攻补兼施，为和解少阳的典型方剂。

---

## 临床应用

### 适应病症
- 感冒、流感见寒热往来、胸胁苦满者
- 慢性胆囊炎、胆石症
- 慢性肝炎、肝硬化
- 乳腺增生、月经不调
- 抑郁症、神经官能症
- 中耳炎、腮腺炎

### 加减变化

| 证型 | 加减 |
|------|------|
| 胸中烦不呕 | 去半夏、人参，加瓜蒌实 |
| 渴 | 去半夏，加重人参、瓜蒌根 |
| 腹痛 | 去黄芩，加芍药 |
| 胁下痞硬 | 去大枣，加牡蛎 |

## 小柴胡汤的衍化

小柴胡汤是"和解剂"的代表方，由此衍化出众多名方：

| 方剂 | 主治 |
|------|------|
| 大柴胡汤 | 少阳阳明合病 |
| 柴胡桂枝汤 | 太少两感 |
| 柴胡加龙骨牡蛎汤 | 少阳痰热扰心 |
| 柴胡疏肝散 | 肝气郁结 |

---

## 禁忌

⚠️ **以下情况慎用或禁用小柴胡汤：**

1. **太阳表证** — 需发汗解表
2. **阳明里实** — 需攻下热结
3. **阴虚内热** — 柴胡劫阴
4. **气机上逆** — 呕吐、呃逆重者

---

## 结语

小柴胡汤被誉为"少阳病主方"，其应用范围极广，古人云"小柴胡汤为半表半里之主剂"，凡见寒热往来、胸胁苦满、默默不欲饮食、心烦喜呕之一二者，皆可考虑使用小柴胡汤。
