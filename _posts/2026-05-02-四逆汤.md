# 四逆汤——少阴病回阳救逆主方

## 出处与组成

四逆汤出自《伤寒论》第323条，是治疗少阴病心肾阳虚、阴寒内盛的回阳救逆代表方。

**组成：**
- 附子一枚（生用，去皮，破八片）
- 干姜一两半
- 甘草二两（炙）

**煎服法：** 以水三升，煮取一升二合，分温再服。

---

## 辨证要点

### 少阴病阳虚阴盛的特征

| 症状 | 机理 |
|------|------|
| 四肢厥逆 | 心肾阳虚，不能温煦四末 |
| 恶寒蜷卧 | 阳虚畏寒，身形蜷缩 |
| 神疲欲寐 | 阳气大虚，精神不振 |
| 呕吐不渴 | 阳虚寒盛，胃失和降 |
| 脉沉微细 | 阳气虚衰，无力鼓动 |

### 四逆汤与当归四逆汤的鉴别

| | 四逆汤 | 当归四逆汤 |
|---|---|---|
| 病机 | 阳虚阴盛（心肾阳衰） | 血虚寒厥（营血不足） |
| 脉象 | 沉微细 | 细欲绝 |
| 治疗 | 回阳救逆 | 养血通脉 |

---

## 方义解析

**附子** — 君药，大辛大热，温肾壮阳，回阳救逆，为"回阳救逆第一品药"

**干姜** — 臣药，温中散寒，助附子温壮元阳

**甘草** — 使药，益气缓中，调和诸药，兼解附子之毒

> 附子温肾回阳，干姜温中散寒，甘草缓和姜附之峻烈。三药配合，共奏回阳救逆、温中散寒之功。

---

## 临床应用

### 适应病症
- 休克、心力衰竭（亡阳证）
- 心肌梗死、心绞痛（阳虚寒凝）
- 急性胃肠炎吐利过度（阳脱证）
- 慢性肾炎、肾功能衰竭（肾阳虚）
- 风寒湿痹（寒痹）
- 阳痿、遗精（肾阳虚衰）

### 加减变化

| 证型 | 加减 |
|------|------|
| 阳虚甚 | 重用附子、干姜 |
| 气虚甚 | 加人参（四逆加人参汤） |
| 浮肿 | 加茯苓、泽泻（茯苓四逆汤） |
| 寒盛格拒 | 重用附子、干姜，冷服（反佐） |

---

## 四逆辈——少阴病阳虚诸方

四逆汤为少阴病阳虚证的基础方，由此衍化出系列方剂：

| 方剂 | 主治 |
|------|------|
| 四逆加人参汤 | 阳虚液脱 |
| 通脉四逆汤 | 阴盛格阳（下利清谷，脉微欲绝） |
| 通脉四逆加猪胆汁汤 | 阳亡阴竭 |
| 茯苓四逆汤 | 阳虚烦躁 |

---

## 禁忌

⚠️ **以下情况禁用四逆汤：**

1. **热厥证** — 真热假寒
2. **阴虚火旺** — 口干、舌红、少苔
3. **实热内结** — 便秘、腹胀、苔黄
4. **孕妇** — 附子堕胎，需慎用

---

## 结语

四逆汤为"回阳救逆"之峻剂，功专力宏，是中医急救的重要方剂。但其药性峻烈，附子需炮制减毒，煎煮得当。临证须准确辨证为阳虚阴盛之证方可使用，切不可用于实热或阴虚之证。
