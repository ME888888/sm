## 条文原文

> **太阳病，外证未解，脉浮弱者，当以汗解，宜桂枝汤。**
> ——《伤寒论》第44条

## 释义

本条论述太阳病在外证未解的情况下，脉象浮弱的治法，提示脉象与治法的关系。

条文承接第42条、第43条，继续讨论太阳病表证不解的辨治原则。

"太阳病，外证未解"——外证，指发热恶寒、头痛、汗出（或无汗）等表证。太阳病虽已汗、下，但表证仍在，仍当解表。

"脉浮弱者"——此处"弱"指相对而言，非沉微无力之弱脉。与第42条小青龙汤证不同，本证无寒饮内停；与第43条误下微喘也不同，本证无里气上逆。脉浮弱提示：
- **浮**：邪在表
- **弱**：营气不足（相对麻黄汤证之"紧"而言）

此脉象与桂枝汤证"阳浮而阴弱"（第12条）相合，提示病在太阳，营卫不和，但表邪不重、里气未伤。

"当以汗解，宜桂枝汤"——浮弱之脉，不可峻汗（麻黄汤类），宜用桂枝汤解肌祛风，调和营卫。

**本条要点：** 太阳病外证未解，脉浮弱者，虽已经过汗下，仍当解表，但宜桂枝汤而非麻黄汤。脉象浮弱是选用桂枝汤的关键指征。

## 病机分析

| 层面 | 病机 |
|------|------|
| 表（太阳） | 外证未解，邪在肌表 |
| 里（营卫） | 营卫不和，脉浮而弱 |
| 整体 | 表邪不重，里气未伤 |

**与前三条的关系：**

| 条文 | 主症 | 脉象 | 治法 |
|------|------|------|------|
| 第42条 | 干呕、咳喘（寒饮） | 紧/浮 | 小青龙汤 |
| 第43条 | 微喘（下后） | 浮 | 桂枝加厚朴杏子汤 |
| 第44条 | 外证未解 | 浮弱 | 桂枝汤 |

## 脉浮弱与脉浮紧的鉴别

| | 脉浮弱 | 脉浮紧 |
|------|--------|--------|
| 含义 | 营卫不和，邪在肌表 | 卫闭荣郁，邪在皮毛 |
| 汗出 | 有汗（桂枝汤证） | 无汗（麻黄汤证） |
| 疼痛 | 身酸痛，不甚 | 身疼痛剧烈 |
| 病机 | 风邪袭表，营弱卫强 | 寒邪束表，卫闭荣郁 |
| 治法 | 解肌祛风 | 发汗散寒 |

胡希恕先生指出："脉浮弱是桂枝汤的典型脉象，与麻黄汤证之脉浮紧截然不同。浮弱为表虚，浮紧为表实，虚实之辨在此。"

## 名家注释

**胡希恕《伤寒论讲座》：**
"本条示人脉象辨证的重要性。太阳病外证未解，或已汗、或已下，只要脉浮弱，仍当用桂枝汤。脉浮弱提示营卫不和，不可再行峻汗。"

**刘渡舟《伤寒论讲义》：**
"'脉浮弱者，当以汗解'——浮为在表，弱为营虚。此与第12条'阳浮而阴弱'同义，皆指桂枝汤证。临证见浮弱之脉，即使已汗、下、表证仍在，桂枝汤仍为主方。"

**郝万山《伤寒论课程讲稿》：**
"本条体现了'观其脉证，随证治之'的原则。不可拘泥于'已汗'、'已下'的治疗经过，而应根据当前脉证决定治法。脉浮弱为桂枝汤证的主要指征之一。"

## 桂枝汤证与麻黄汤证的鉴别

| | 桂枝汤证 | 麻黄汤证 |
|---|---|---|
| 条文 | 第42、44条 | 第35条 |
| 脉象 | 浮弱（阳浮阴弱） | 浮紧 |
| 汗出 | 有汗（自汗） | 无汗 |
| 恶寒 | 恶寒轻 | 恶寒重 |
| 身痛 | 身酸痛，不甚 | 身疼痛剧烈 |
| 喘 | 无（或喘家新感，第18条） | 有喘 |
| 病机 | 风邪袭表，营卫不和 | 寒邪束表，卫闭荣郁 |
| 治法 | 解肌祛风，调和营卫 | 发汗散寒，宣肺平喘 |

## 临床应用

1. **感冒后表证未解、汗出不解**——外感后已用发汗药，但发热恶寒仍在，汗出脉浮弱者
2. **太阳中风后遗症**——发热汗出、恶风、脉浮缓时日迁延者
3. **体虚感冒**——素体虚弱，反复感冒，症见发热恶风、汗出脉浮弱者
4. **过敏性鼻炎**——属表虚不固，风邪外袭者

## 总结

第44条论述太阳病外证未解、脉浮弱的治法，是桂枝汤临床应用的重要指征。

**辨证要点：**
- **外证未解**：发热恶寒、头痛等表证仍在
- **脉浮弱**：与麻黄汤证脉浮紧相对，提示营卫不和、表邪不实

**治法**：解肌祛风，调和营卫——桂枝汤

本条与第12条（桂枝汤证脉象）互参，揭示桂枝汤的辨证核心在于"阳浮而阴弱"的营卫不和病机。
